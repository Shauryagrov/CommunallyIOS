## 🆘 Need Help?

### Common Issues

**Q: Packages won't resolve**  
A: File → Packages → Reset Package Caches

**Q: Build errors**  
A: Clean Build Folder (`⌘+Shift+K`), then Build (`⌘+B`)

**Q: Code signing issues**  
A: Xcode → Settings → Accounts → Add your Apple ID

**Q: Firebase not connecting**  
A: Check `GoogleService-Info.plist` is in project target

**Q: Simulator not available**  
A: Xcode → Settings → Platforms → Download iOS
